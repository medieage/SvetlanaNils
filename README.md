# Светлана Нильс — Перо Феникса

Сайт на Next.js, React и TypeScript. Русскоязычная адаптивная страница с услугами, ценами, переключателем ghostwriting и контактами ВКонтакте.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

## Проверка и сборка

```bash
npm run build
npm run typecheck
```

Настроен статический экспорт: готовый сайт находится в `out/`. Эту папку можно разместить на статическом хостинге и подключить домен svetlananils.ru. Домен в метаданных не означает, что домен зарегистрирован или подключён.

Контент и ссылки: `app/page.tsx`. Оформление: `app/globals.css`. Метаданные: `app/layout.tsx`.

«Мои книги» и «Курсы» отображаются с пометкой «скоро», без ссылок. Все кнопки заказа ведут на личную страницу ВКонтакте; ссылки сообщества — в группу. На первом экране используется предоставленная композиция «Перо Феникса», в анонсе курсов — афиша «Код крови». Изображения находятся в `public/images/`; исходный PNG сохранён как `pero-feniksa-original.png`.
